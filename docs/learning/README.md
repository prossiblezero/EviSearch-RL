# 只学当前实现：六课读懂证据 Agent

目标不是照着实验时间线学习五套代码，而是从一次交互出发，理解当前系统的数据、训练与证据链。六课都使用 `evisearch` 中同一套实现，没有教学版训练器与生产版训练器的分叉。

先具备 Python、JSON 与基本监督学习知识即可。第 1、5 课的最小例子不需要 GPU 或模型；涉及分词器、TRL 和真实数据的检查使用[复现说明](../reproduction.md)中的专用环境。先运行 `python -m evisearch.demo`，看一遍结果，再按顺序阅读。

| 课 | 只解决一个问题 | 读完应该能解释 |
|---|---|---|
| [01 一次交互](01-agent-loop.md) | 模型怎样从问题走到带引用的答案？ | 模型负责决策，环境负责真实执行与状态 |
| [02 工具与证据](02-evidence.md) | 为什么搜索、阅读、保存必须分开？ | 发现、已读、可引用是三个不同集合 |
| [03 数据与 SFT](03-data-and-sft.md) | 示范如何成为正确的训练信号？ | 回放验真、特权监督、assistant-only mask |
| [04 在线 RL](04-grpo.md) | 怎样从四条真实轨迹里学策略？ | 同起点、组内优势、零方差、冻结参考 |
| [05 声明奖励](05-vcr.md) | 如何给中间判断直接反馈？ | VCR 如何验证、如何写入逐 token 优势 |
| [06 评测与归因](06-evaluation.md) | 什么证据才支持“方法有效”？ | 完整分母、同模式比较、配对区间与局限 |

每课包含问题、当前代码定位、可运行入口和自检题。这里采用“一课一个机制”的组织方式，参考 [learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)，没有复制它的多版本教学代码结构。

完成后，再阅读[演化故事](../evolution.md)，理解为什么本项目最后特别关注“读到了什么”与“模型认为自己读到了什么”之间的差异。故事不是运行代码的前置条件。
