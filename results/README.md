# 当前结果：先判断行为变化，再判断答案收益

本页只说明当前多工具环境下的证据。历史环境的整张结果表不再发布；过去的负结果与决策保留在[演化故事](../docs/evolution.md)。

## 协议与指标

- 每个 dev2/test 划分均为 512 个 MuSiQue 问题；同一题的候选文档固定，使用本地 BM25。
- 三个主对照都从同一 `sft_err` 适配器开始，冻结同一适配器作为 reference。公开代码将这个起点简称为 `sft`。
- RL：1,024 组 × 4 条轨迹，两次优化/组，2,048 次更新；seed 42。
- 评测：greedy，单轮至多 512 个新 token，轨迹预算 6,144，序列上限 8,192；工具预算 3/8/8。
- EM 为规范化答案精确匹配；报告的答案 F1 为词频口径，训练终局使用 token-set F1，两者不可混称。
- 证据完整率为引用覆盖全部标注支持文档的题目比例，不是平均 evidence coverage，也不是自然语言蕴含证明。
- 提前停止：最终格式有效、证据不全且 search 调用少于 3 次。它是本项目的行为指标，并不判定所有停止决策都错误。
- 配对区间用相同任务的 5,000 次 bootstrap，只反映任务抽样，不包含训练随机性。

## 同起点的主要比较

| 划分 | 方法 | EM | F1 | 证据完整率 | 提前停止率 |
|---|---|---:|---:|---:|---:|
| dev2 | GRPO | 62.30% | 69.81% | 68.75% | 23.24% |
| dev2 | IGPO | 61.13% | 68.21% | 66.60% | 24.02% |
| dev2 | VCR | 60.94% | 67.16% | 70.31% | 16.41% |
| test | GRPO | 56.25% | 66.66% | 64.26% | 28.12% |
| test | IGPO | 52.54% | 61.14% | 62.30% | 27.15% |
| test | VCR | 56.84% | 65.13% | 67.19% | 17.19% |

VCR−GRPO 的 test EM 为 +0.59pp [−2.93, +4.30]；dev2 EM 为 −1.37pp [−4.69, +1.95]。因此没有“VCR 稳定提高 EM”的证据。test 提前停止差为 −10.94pp [−14.65, −7.23]，dev2 为 −6.84pp [−9.96, −3.91]；这一行为变化在两个划分上方向一致。

历史配对报告中，VCR 比 IGPO 的 test EM 高 4.30pp，区间 [0.20, 8.40]；但 dev2 没有对应的 EM 优势。这仍然是单种子、反复研究过的题集上的观测，不能泛化成算法排名。

## SFT 到底改变了什么

| 相同模式、相同 512 题 | Base EM | 原教师 SFT EM | Base 格式合规 | SFT 格式合规 |
|---|---:|---:|---:|---:|
| Agent 自主调用工具 | 6.25% | 43.75% | 12.30% | 100.00% |
| 相同静态检索材料 | 13.67% | 18.95% | 99.22% | 100.00% |

`report.py` 对静态模式逐题核对两模型收到的 system/user 消息完全一致，并从实际预测重新聚合结果。Agent 的大幅变化包含协议与工具控制的改善；静态材料对照更接近排除检索策略差异后的答题变化，两种模式不能交叉归因。

原教师 SFT 不是当前三组 RL 的起点：当前起点加了相关性推理示范，在 dev2 的 EM 为 58.01%，原教师 SFT 为 54.49%。当前起点缺少独立完整 test 评测，因此本页不填造它的 test 数字，也不把 43.75→56.84 当作 VCR 的单因素贡献。

## 哪些限制仍在

1. test 虽与训练数据隔离，但在多轮研究中已经被查看。它是复用的留出集，不是本轮新冻结的盲测集。
2. 主对照只有一个训练种子。原 GRPO 的多种子结果曾有 52.34–53.91% 的波动，但那是另一 SFT 起点，不能据此给当前三组计算方差。
3. 声明准确率 63.2%→69.4%、干扰阅读后补救率 2.3%→13.9% 来自 dev2 审计，不能写成 test 指标。IGPO 的该补救指标更高，VCR 不是所有行为指标都最好。
4. 历史三组训练存在明确记录的并行运行，耗时不能作公平效率对比；当前公开运行说明采用串行。
5. 金标支持文档、子问题及子答案是训练期特权监督。声明验证采用固定句式与阈值，无法验证任意自然语言推理。
6. 没有开放网络搜索、开放语料检索或临床验证。MedHop 扩展中的实体共现仅是代理指标。
7. 代码整理后的 GPU 全流程尚未重跑。CPU 契约通过与已有结果重算不等于新实现的训练复现实验已完成。

## 如何核对

运行 `python report.py`，从仓库外的真实预测重算 [current.json](current.json)。摘要包含题集与预测文件 SHA-256、完整分母、Base/SFT 对照、当前三组指标及配对区间。缺少产物、分母不全、协议或摘要哈希不匹配时直接失败，不预填成绩。

生成新的训练结果后，使用 `python -m evisearch.evaluation.compare vcr-42 grpo-42 igpo-42`，它只读取 `runs/release/eval` 中完成的评测，不会把历史结果当作新结果。
