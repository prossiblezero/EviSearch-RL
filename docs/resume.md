# 简历项目条目

**EviSearch-RL：基于可验证声明奖励的证据溯源多跳检索 Agent**

**项目简介**：单轮 RAG 面对多跳问题时难以拿全桥接证据，答案也缺少可核验的引用。本项目训练小模型多轮检索、阅读并保存证据，在固定工具预算下给出带原文引用的答案。

- **数据与环境**：基于 MuSiQue 构建本地 BM25 检索环境和 Search / Read / AddEvidence / Answer 结构化动作空间，答案只能引用已保存的证据。用 DeepSeek 在真实工具环境中合成并回放校验 1,800 条 Agent 轨迹，补充逐跳相关性推理，构建 6,000 条 SFT 数据和 1,024 道 RL 题，评测使用相互独立的 dev 与 test 各 512 题。
- **训练方案**：对 Qwen3.5-2B 做 LoRA SFT，工具返回内容不计入损失；再用 TRL 原生工具执行做 on-policy GRPO。在同等预算下系统对比 DAPO、GSPO 和 9B 教师在线蒸馏，并为每个新方法设置训练前的离线验证。
- **奖励设计**：终局奖励为答案 F1 × 证据 F1，伪造引用、非法调用等记 −2。复现 IGPO 信息增益轮次奖励作为基线后，提出可验证声明奖励（VCR）：把模型每轮写出的“某文档回答第 k 跳”与数据标注逐条核验，作为轮次级奖励。通过轨迹审计修复了失败动作获得正优势等奖励漏洞。
- **实验结果**：test EM 从 Base 的 6.3% 提升到 SFT 的 43.8%、GRPO 的 53.9%，最终达到 56.8%。VCR 比 IGPO 信息增益奖励 EM 高 4.3 个百分点，相比 GRPO 提前停止率从 28% 降至 17%。
